# ⚡ CodeHub

A targeted C++ & Data Structures coursework portal built specifically for classroom lecture tracking, lab assignments, and homework practice.

🔗 **Live:** [https://codehub-16lp.onrender.com](https://codehub-16lp.onrender.com)

---

### Features
* **Syllabus-Aligned:** Curated problems directly mapped to classroom lectures and lab tasks.
* **Dual Tracks:** Dedicated roadmaps for **DSA** and **Core C++** (OOP, pointers, memory models).
* **Work Types:** Clear separation between **Classwork** examples and **Homework** exercises.
* **Instant Filter & Search:** Real-time filtering by topic tags and keywords.
* **Reference Solutions:** Clean C++ implementations with syntax highlighting and one-click copy.
* **Admin Access:** Press `Ctrl + Shift + A` anywhere on the site to manage questions.

---

### Tech Stack
* **Frontend:** HTML5, CSS3 (Glassmorphism), Vanilla JS, Prism.js
* **Backend:** Node.js, Express.js
* **Database:** SQLite3 (`codehub.sqlite`)
* **Hosting:** Render
